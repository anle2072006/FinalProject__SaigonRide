# 🛵 SaigonRide - Trải nghiệm Sài Gòn trên từng bánh xe
SaigonRide là dự án cuối khóa (Final Project) được xây dựng với tình yêu dành cho nhịp sống hối hả của Sài Gòn. Đây là một nền tảng quản lý và đặt chuyến xe trực tuyến, giúp kết nối người dùng với những hành trình an toàn, tiện lợi ngay trong lòng thành phố.

Cho dù bạn là một du khách muốn khám phá từng con hẻm nhỏ hay là một "Sài Gòn chính hiệu" cần một chuyến đi nhanh chóng để kịp giờ làm, SaigonRide sinh ra để giải quyết điều đó.

## ✨ Tính năng nổi bật
Đặt xe nhanh chóng: Giao diện thân thiện, tối ưu hóa thao tác người dùng.

Quản lý hành trình: Theo dõi lịch sử chuyến đi và lộ trình trực quan.

Hệ thống phân quyền: Phân chia rõ ràng giữa người dùng (Rider) và quản trị viên (Admin).

Tương thích đa nền tảng: Chạy mượt mà trên trình duyệt nhờ khả năng tương thích cao.

## 🛠 Công nghệ sử dụng
Dự án là sự kết hợp giữa tư duy lập trình hiện đại và quy trình triển khai chuyên nghiệp:

Backend/Frontend: (Bạn hãy điền ngôn ngữ chính vào đây, ví dụ: Node.js/React hoặc Java/Spring Boot).

Database: Quản lý dữ liệu thông minh với MySQL/PostgreSQL.

Containerization: Docker - giúp việc đóng gói và vận hành đồng nhất trên mọi môi trường.

Deployment: Tự động hóa triển khai (CI/CD) qua Render.

## 🚀 Hướng dẫn cài đặt (Local Setup)
1. Clone Source Code
Bash
git clone https://github.com/anle2072006/FinalProject__SaigonRide.git
cd FinalProject__SaigonRide
2. Chạy với Docker
Không cần cài đặt môi trường phức tạp, chỉ cần máy bạn có Docker:

Bash
docker-compose up --build
Hệ thống sẽ tự động kéo Image, cài đặt thư viện và khởi chạy tại: http://localhost:8080

## 🌐 Triển khai Online (Render)
Dự án đã sẵn sàng để "lên sóng" với Render:

Tạo một Web Service mới trên Render.

Kết nối với repo GitHub này.

Chọn môi trường chạy là Docker.

Render sẽ tự động đọc file Dockerfile và cấp cho bạn một đường link https://saigonride.onrender.com.
